修复

  • 修复高 DPI（150%/200%）下可视化模块坐标偏移：鼠标高亮/点击效果/轨迹/聚光灯/放大镜统一经 dpiutil 物理→逻辑换算后绘制，不再错位 1.5 倍
  • 修复放大镜截屏源区域：物理截屏源边长按该屏缩放比换算（magnifier_size 为逻辑像素），混合缩放下放大倍率不再漂移、看到的桌面范围正确
  • 修复键盘/鼠标坐标"自定义位置"观感与设定值不符：自定义 X/Y 统一按物理像素语义解释（与鼠标坐标显示一致），绘制前转逻辑坐标
  • 修复浮动工具栏在 150% 缩放下飘出屏幕外不可见：显示时按主屏可用区钳制位置，旧的低 DPI 保存值自动贴回右下角
  • 修复托盘右键菜单在高分屏放大 200% 时位置错乱：弃用 QSystemTrayIcon.setContextMenu（高 DPI 定位有偏移 bug），改为右键时手动 menu.popup(QCursor.pos())
  • 修复托盘创建崩溃「托盘不可用」（QMenu(parent) 参数类型错误）：TrayController 是 QObject，原误用 QMenu(self) 把自身当父对象；QMenu 需 QWidget 父对象，改为用 __init__ 传入的主窗口 QWidget
  • 修复主窗口点击效果层（涟漪/光晕/键盘提示）在全局逻辑坐标绘制未减 widget 偏移导致副屏错位
  • 修复多屏混合缩放下放大层跟屏判定：放大镜跟随用逻辑坐标 contains 逻辑 geometry，跨屏不再错
  • 修复 2880×1920 在 200% 缩放下鼠标效果仍错位（100% 正常、200% 偏移约 2 倍）：根因是 PerMonitorV2 叠加 AA_EnableHighDpiScaling 时 QScreen.devicePixelRatioF() 会误报缩放比（如 200% 屏报成 1.0）。dpiutil 不再信任 devicePixelRatioF，改为用「匹配到的 物理尺寸 ÷ 逻辑尺寸」实测比值作为有效缩放比，免疫 DPR 误报
  • 修复启动崩溃（dpiutil._build_pairs 元组解包错误导致 refresh_caches 抛 ValueError，主窗口创建即中断）

2.1.26255.2216

2026-09-12

变更

  • 大版本升级 2.0 → 2.1
  • 编辑公共动作时的三选一确认框窗口拉宽至 640px

新增

  • 动作 / 节点新增「公共模板」与「私有实例」两种形态：公共实例（🔗）关联 动作库 / 节点库中的模板，模板改动自动同步到所有引用处；私有实例（🔒） 内嵌于当前方案或节点，不入库、不进分类树，跟着方案一起走。
  • 方案文件全面自包含：节点、动作及其全部参数都随方案文件一起内嵌保存， 单个方案文件即可直接分享给他人，接收方无需预先拥有相同的动作 / 节点库。
  • 节点编辑器新增「来源」列，逐行标出动作是公共（🔗）还是私有（🔒）。
  • 节点编辑器支持把动作「转为公共」：填写名称与分类后写入动作库并变为公共实例； 重名会提示改名，若不改名则拒绝入库（不做自动加后缀）。
  • 分享方案的导入升级为智能匹配：命中本地同 ID 的模板则保持公共并刷新快照， 未命中的节点 / 动作自动降级为私有副本，导入后即可直接运行。

变更

  • 执行引擎改为「快照执行」：运行动作时直接使用方案 / 节点内已保存的参数副本， 不再回查动作库，因此方案即使脱离原动作库也能照常运行。
  • 公共实例的改动沿引用链自动同步：保存或重命名动作 / 节点模板时，所有引用它的 节点与方案快照一并刷新；删除模板时引用处自动降级为私有副本，方案仍可运行。
  • 编辑公共实例改为每次都弹出二次确认：可「修改模板（全局生效）」、 「仅改这一份（转为私有）」或取消（默认聚焦在取消上），避免误改影响其它方案。
  • 新增动作 / 节点的入口默认创建私有实例，只有明确执行「转公共」才写入动作库 / 节点库。
  • 数据格式升级为 v2（fmt:2）。旧数据在首次启动时自动迁移为公共引用，迁移前会完整备份到 userdata/.backup/v2_<时间戳>/ 并写入 v2_done 标记； 旧格式文件在内存内自动归一，保存后即转为新格式，原有数据无需手动处理。
